# rankcell

Rank identifiers and cell tokens for idempotent workflows.

**Site:** https://theworker02.github.io/rankcell/

## Install / run

```bash
git clone https://github.com/theworker02/rankcell.git
cd rankcell
node src/cli.js
node --test
```
